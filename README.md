# tourvisor-vk-bot

Бот, который раз в день собирает горящие туры Екатеринбург → Вьетнам с tourvisor.ru,
складывает их в SQLite и рассылает дайджест в ЛС от имени сообщества ВК
(карусель карточек: фото, старая/новая цена, ночи, даты вылета и прилёта;
если туров больше 10 — несколько сообщений-страниц).

## Откуда данные

Используется неофициальный эндпоинт виджета tourvisor
`https://tourvisor.ru/xml/modhot.php?format=json&city=3&countries=16`
(город вылета `city=3` — Екатеринбург, `countries=16` — Вьетнам).
Коды других городов/стран можно посмотреть так:

```
curl "https://tourvisor.ru/xml/listdev.php?format=json&type=departure&cndep=1"
curl "https://tourvisor.ru/xml/listdev.php?format=json&type=country&cndep=3"
```

Эндпоинт неофициальный — может поменяться без предупреждения.

## Настройка

1. Создай сообщество ВК → Управление → Работа с API → создать ключ доступа
   с правами на **сообщения**. В «Сообщения → Настройки для бота» включи
   «Возможности ботов» (нужно для карусели).
2. Получатель должен разрешить сообщения от сообщества (написать ему первым
   или нажать «Разрешить сообщения»).
3. `cp .env.example .env` и заполни `VK_TOKEN`, `VK_PEER_IDS`.

## Запуск

```bash
cargo run --release            # демон: спит и срабатывает каждый день в RUN_AT
cargo run --release -- --once  # разовый прогон (для проверки)
```

## График цен

После карточек бот строит график «минимальная цена тура по дням вылета»
на месяц вперёд и шлёт его картинкой. Данные берутся из настоящего поиска
tourvisor (`modsearch.php` → `modresult.php`) с учётом `ADULTS` (по умолчанию 2)
и длительности `NIGHTS_FROM`–`NIGHTS_TO` (по умолчанию 8–11 ночей).
Карточки горящих туров тоже фильтруются по этому диапазону ночей.

## Окно вылета

Берутся туры с вылетом строго позже, чем через `WINDOW_FROM_DAYS`, и строго
раньше, чем через `WINDOW_TO_DAYS` дней от сегодня (по умолчанию 5 и 12).
Если в окне ничего нет, бот так и напишет в дайджесте.

## БД

SQLite-файл (`DB_PATH`, по умолчанию `tours.db`), таблица `hot_tours` —
дневные снимки. Уникальность по `(tour_id, fetched_on)`: повторный запуск
в тот же день дублей не создаёт.
